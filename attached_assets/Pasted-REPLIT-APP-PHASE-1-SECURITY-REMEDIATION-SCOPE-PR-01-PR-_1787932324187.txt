not verify current authoritative account state.

Inspect:

artifacts/api-server/src/middlewares/auth.ts

- login/token issuance

- user schema
- session-related schema, if any

At minimum evaluate:

A. suspension
B. deactivation

Compare possible remedies:

Assess:

- security

==================================================

Previously reported code contains a predictable fallback signing secret when
SESSION_SECRET is unavailable.

Inspect all locations where:
