==================================================
PRIMARY DEFECT TO CONFIRM
==================================================

Previously observed:

Role-related values are stored as JSON arrays/text and updated using:

READ CURRENT VALUE
→ MODIFY IN APPLICATION MEMORY
→ WRITE WHOLE NEW VALUE

If two valid requests occur concurrently:

Request A reads:
[parent]

Request B reads:
[parent]

A writes:
[parent, teacher]

B writes:
[parent, support]

Possible final state:

[parent, support]

Teacher is silently lost.

Confirm whether this can actually happen in the current implementation.
